# موقع كي بلاس — دليل التشغيل والسيو

## الملفات
- `content.py` كل النصوص والمنتجات والأسئلة وبيانات التواصل (عدّل هنا).
- `build.py` بيولّد الموقع: `python3 build.py` → فولدر `dist/` جاهز للرفع.
- `assets/` التصميم (CSS) واللوجو وصورة المشاركة.
- `kplus-site-dist.zip` نسخة جاهزة للرفع.

## قبل الرفع (لازم)
1. في `content.py` حط: رقم التليفون، الواتساب، الإيميل، العنوان، إحداثيات المقر، والدومين النهائي.
2. ابعت اللوجو الحقيقي ونستبدل `assets/logo.svg`.
3. صور حقيقية للمنتجات والمشروعات (بتفرق جدًا في الترتيب والتحويل).

## الرفع (مجاني وسريع)
- Cloudflare Pages أو Netlify: ارفع فولدر `dist/` واربط الدومين. ملف `_headers` بيظبط الكاش.

## خطة الظهور الأول في جوجل
1. **Google Business Profile** باسم "كي بلاس لتوريد مواد البناء" بنفس العنوان والتليفون — ده أهم عامل للظهور في الخريطة لبحث "توريد أسمنت بالقرب مني".
2. **Google Search Console**: أضف الدومين وابعت `sitemap.xml`.
3. محتوى أسبوعي: مقال عن أسعار الأسمنت/الحديد/الطوب الشهرية (أكتر كلمات بحث في المجال).
4. روابط خارجية: أدلة مصرية (يلا دليل، دليل مصر، أوليكس، فيسبوك بيزنس)، وموقع الكنانة يربط لكي بلاس.
5. تقييمات جوجل من العملاء (جيدار، الشروق، كونكريت بلس…).
6. إعلانات جوجل لكلمات "توريد أسمنت" و"أبواب مقاومة للحريق" في أول 3 شهور لحد ما الترتيب العضوي يطلع.

## السيو التقني الموجود
- عنوان ووصف فريد لكل صفحة بكلمات البحث المصرية.
- Schema: LocalBusiness، Product، FAQPage، BreadcrumbList، WebSite.
- hreflang عربي/إنجليزي، canonical، sitemap بالروابط البديلة، robots.txt.
- موقع ثابت خفيف جدًا (بدون مكتبات)، متوافق مع الموبايل.
